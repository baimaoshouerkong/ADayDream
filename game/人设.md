# 游戏名字
白日梦
# 角色设定
## 男主
- 无名
- 一个失意之人，在现实里找不到自己的存在感
## 女主
- 学姐（名字就是这个）
# 故事简介
我在现实里迷失了自己，经常一个独自待在一个没有人的角落。某天，在学校的一个角落我一个人静静的待着，突然一个神秘但是也是孤独的女生也走进来，她是我的学姐，第一次见面我们两个人自然的分出了界限，度过这一天。
第二天学姐也是一个人来到了这个角落，我也一个人待在这里，我们两个人又自然的分开了界限，度过了这一天。
过了几天我终于鼓起勇气和学姐说话了，学姐告诉我她是来寻找自己自我的，朋友眼中的自己，自己眼中的自己，昨天的自己，现在的自己，明天的自己，那个才是真正的自己。我听罢陷入了沉思，我没有什么朋友，或者说没有深层的联系，没有人会来一直主动和我说话，仿佛这个世界没有我的位置一样。我们第一次互相交流了一下。于是我们又一次在一个相同的空间里度过了一天。
又一天，我们再次在角落相会，也许是同一种感觉的共鸣，学姐先开口了，我们建立了一个契约，学姐每天都会和我在这里相见，直到其中一个人寻找到自己。
## 事件A
一天我与学姐在角落里相会，我问学姐你心目中人和人之间的相处是什么？
学姐的观点为任何人都是之间的关系都是一种契约，无论什么感情，都是两个人的相互回馈，但是这个契约十分脆弱，一旦有一方决定毁约，那么契约就结束了。
## 事件B
一天我与学姐在角落里相会，学姐问我你为什么会这么孤独？
我的回答：人活在世界上是靠自己的，但是周围的一切都在否定着我，所以我与这个世界的锚点丢失了。
学姐笑笑，你的缺失是否定，我的缺失是妥协

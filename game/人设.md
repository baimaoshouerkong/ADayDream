# 故事大纲
男主家和女一悠青青一家关系很好，所以男主也得以和女一慢慢认识。而有一次出门的时候，被淹死，悠青青一家办完葬礼后选择离开这里。男主的心理完全失衡，无法面对现实，为了防止自己崩溃，他在心里虚构女主和家人搬走的记忆。
在艰苦的学习生活中每当夜晚时男主总会梦见女主，梦见她和自己在一起，这件事也成为了男主的支柱。到了大学，作为边缘人的男主尝试联系悠青青，潜意识却在抗拒着，社团随便加了个，课程也是随便去去。因为一次小组作业要差玛奇朵的那份男主其他人都不想在玛奇朵面前留下坏影响于是这事就落到男主的头上
出门的时候撞到玛奇朵，玛奇朵也让男主等她回到宿舍再来找她。男主无意间看到她的脸上满是堆笑，又回忆起女主的笑，驻足片刻，阴暗的男主立马就被玛奇朵的同伴针对了。玛奇朵帮忙圆场，但是矛头由一个人转到两个人。心理压力使男主再次想起女主，在女主的支持下，男主反抗起来。玛奇朵的同伴欺软怕硬，于是就走开了。
玛奇朵对男主的勇敢表示赞赏，男主也因此和玛奇朵熟悉了起来。玛奇朵也带着男主尝试着走出自己的舒适圈，开始享受校园生活。
于是，碰到何雨语，得到了悠青青已死的消息，男主的心理防线彻底崩溃。在幻想中的女主的安慰和鼓励下，男主走出了阴影。
